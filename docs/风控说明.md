## 绝对封顶阈值

AbsoluteCap  float64 // 绝对封顶阈值，  最大容忍亏待额度 AbsoluteCap（绝对封顶阈值）：给每个开奖号码的“潜在赔付”（PotentialPayout/Exposure）设置的硬上限。超过就必定触发风控动作（转单/限流/停收），不受其他柔性策略影响。
	


## 风险比例

RiskRatio（风险比例 = PP / NetBank）

定义：风险比例。PP 是该号码在当前订单池的潜在赔付（Potential Payout）；NetBank 是你的净盘子/可承受资金基数。RiskRatio = PP ÷ NetBank。
用途：
    统一不同规模盘子的风险尺度，方便跨期、跨彩种比较。
    与阈值线对比，用于触发告警、入榜和对冲动作。
    口径建议：
    PP 要扣减“已对冲可抵消的赔付贡献”，用净风险更准确。
    NetBank 建议用“可用于当期赔付的净资金或预算”，可随时段动态调整（近封盘下调）。
    常见阈值参考：
    告警线：0.7
    动作线：0.8
    绝对上限：1.0（或配合 AbsoluteCap 的金额口径）
注意：
    分玩法赔率差异大时，RiskRatio 对高赔率玩法更敏感，属于预期行为。
    NetBank 变化时（充值、提前划转、预留金变更）要自动重算 RiskRatio。

## 目标限额

TargetLimit 像“回压到这里”的安全线。线高就少打、线低就多打，怎么取舍看你想吃多少风险、外部能接多少。

TargetLimit（目标限额）

    若你能快速、稳定地以较高赔率承接（对冲资源充足）：可把 TargetLimit 调低一点（0.35～0.45），更积极控盘。
    若外盘容量有限或波动大：把 TargetLimit 调高一点（0.45～0.6），减少过度对冲导致的成交困难。
    若封盘前承接效率下降：封盘前下调 TargetLimit（例如常规 0.5，封盘前10分钟降到 0.4）。
    四、按玩法分层设置

    高赔率玩法（如直选900、组六150）：TargetLimit 取值更低（例如 0.35～0.45×NetBank），因为波动和尾部风险更强。
    低赔率玩法（如独胆/包对一 3.3）：可适当提高（0.45～0.6×NetBank）。
    若你按号码组（例如组选拆分后的直选号聚合）做风控，按“最终赔付口径”一致来定层。

定义：当一个号码被判定“超线”后，希望把它压回的目标安全水平。可同样支持比例或金额口径。
    比例口径例：TargetLimit = 0.5×NetBank → 对应金额目标线 = 0.5×NetBank。
    金额口径例：TargetLimit = 500,000 元。
用途：
    计算需要转走的赔付额度：TransferPayout = max(0, PP - TargetLimitAmount)。
    生成建议对冲本金：TransferStakeHint ≈ TransferPayout ÷ AvgOdds。
配置建议：
    通常小于 Threshold，形成“回压空间”（例如 Target 0.5，Threshold 0.8）。
    近封盘可进一步下调（如 0.5 → 0.4），留出尾盘缓冲。
注意：
    如果只用比例口径，要在每次计算时用最新 NetBank 换算成金额目标。
    多轮对冲时，TargetLimit 是“收敛目标”，每一轮可分批接近，避免一次吃满。


## 平均赔率

AvgOdds（平均赔率） 用于算出需要转出的本金
定义：用于估算或执行对冲时采用的“平均赔率”。它决定“转走赔付需要下多少本金”。 有两种实务口径： 
    a) 内盘估算口径：暂时没有外部承接报价时，用本系统该玩法的赔率作为估算值（或按拆分号的加权平均）。 
    b) 外盘执行口径：实际对冲时，基于外部多家盘口的可成交赔率与权重，计算成交加权均价。

用途：
    建议本金：TransferStakeHint ≈ TransferPayout ÷ AvgOdds。
    执行后回写：用实际成交均价替换估算值，便于事后复盘与下一轮精确计算。
计算建议：
    多对手盘拆分成交时，AvgOdds = Σ(成交额i × 赔率i) ÷ Σ成交额i。
    对于组选拆分到多个直选号的情况，如果你按“拆分后的具体直选号”去对冲，AvgOdds 应取直选号维度的外盘赔率均价；若你在外盘也以组选产品对冲，则取组选产品赔率。
注意：
    赔率随时间可能变化，近封盘波动更大。建议：下单前短时锁价或允许一定滑点；执行后以实际成交赔率回写。
    不同玩法赔率不同，AvgOdds 必须与被对冲的“风险口径”匹配，否则建议本金会偏差。


一句话总结
AbsoluteCap 是“每个开奖号码可承受的最大赔付敞口”的硬上限。即使你平时不限额，它仍应该存在，来自你的风险承受能力/外部承接能力/历史极值等综合评估。超过它就必须马上转移风险或临时收紧该号，防止极端亏损。

RiskRatio 统一风险尺度，判断“多危险”。
Threshold 决定“是否动手”。
TargetLimit 决定“把它压到哪里”与“要转走多少风险”。
AvgOdds 决定“要用多少本金去对冲这份风险”。
